# HELIX Showcase — Repository Setup

## Recommended Repository Name

**helix-showcase**

## GitHub Setup

```bash
git remote add origin https://github.com/YOUR_USERNAME/helix-showcase.git
git branch -M main
git push -u origin main
```

## Vercel Deployment

```bash
npm i -g vercel
vercel --prod
```

Or connect your GitHub repo directly in the Vercel dashboard.

## Recommended Domain

- `helix.build` or `helix-showcase.vercel.app`
